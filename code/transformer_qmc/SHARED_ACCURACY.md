complete. Downloaded records are in `data/kagome/transformer_af_shared_accuracy_v1`.
The checkpoint has not passed accuracy qualification. The executed investigation
is `notebook/shared_alibi_symmetry_diagnostics.ipynb`, generated by

At 12 spins, explicit even-parity projection largely corrects the zero-field
disorder-0 failure (fidelity 0.501918 to 0.996688), but disorder-1 correlations

consistency in one shared model. The diagnostic preserves all checkpoint weights.

The user requires one set of ALiBi weights, conditioned on L, quenched bonds,
Γ and h. Loading a separate specialist or fine-tuning for each size does not
satisfy this requirement. The extended specialist campaign was deliberately
stopped and its checkpoints preserved. Its interrupted-monitor message is
expected, not a training numerical failure.

The shared model has width 64, four causal ALiBi blocks and four heads. All
24 original contexts are retained: L=2,4,6,8 × disorder IDs 0,1 × field pairs
(0.5,0.3), (2,0.3), (0.5,0). Distillation for 2,400 updates initializes a
single student from existing specialist teachers at the benchmark points and
the original shared teacher elsewhere. This initialization uses model-generated
samples and conditional probabilities, not exact ground-state labels.

Physical VMC then runs 6,000 shared optimizer updates, batch 256 per context.
Every update accumulates gradients from ALL FOUR sizes before changing any
parameter. The disorder/field pair cycles through six combinations; every
context therefore receives 1,000 VMC batches. The objective weights each
context's energy per spin equally. Gradients are clipped only after summing
all four size contributions. A single optimizer and one parameter state serve
the whole campaign. Distillation and physical training have separate optimizers.

Every 600 VMC updates, one snapshot is evaluated across all 24 contexts without
training or changing weights. At L2, full enumeration and exact references
assess energy and connected/raw observables. The final artifact is evaluated
on all 24 training contexts plus disorder ID 2 at every size, with independent
sampling streams. These checks do not establish accuracy at arbitrary unseen
sizes or fields; those require separate validation before production GFMC.
