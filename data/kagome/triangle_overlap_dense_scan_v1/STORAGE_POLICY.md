# Campaign storage policy

User instruction: large campaign files stay remote on AutoDL. Do not download
large raw results, checkpoints, states, isometries, model archives, or campaign
directories to the local machine, including as a way to free remote disk space.

Run scientific extraction, analysis, and figure generation remotely. Fetch only
small reports, metadata, and concise notebooks with embedded figures on demand.
Do not run a persistent local fetcher. Preserve remote scientific artifacts;
storage pressure is a resource constraint for further dispatch.
