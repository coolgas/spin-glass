# Shared PBC GFMC production pipeline

## Scientific scope

All anchor sizes **L=4,6,8,10** have the same 49 field contexts, initially 64 fresh disorders, four independent population repeats, a fixed 16-disorder unguided comparison subset, the same observables and common numerical acceptance criteria. L=5,7,9 add matched transition cuts. Each anchor survey requires 15,680 population runs before qualification/audits; the four-anchor total is 62,720.

The base queue is the notebook's **Section 5 Stage B pilot**: L=4, W=64 four-replica walker groups, equilibration 2, energy measurement 1, forward time 1, four cycles and branch interval 0.1. Four development disorders, Gamma=0.5,1,2, h=0,0.15,0.3, two methods and four repeats give **288 runs**, using float64 for both methods.

The detached `research_followup.py` controller waits for all base results and successful supervisor completion, then acquires the same `pipeline/supervisor.lock`. Its **144 runs** use fixed disorder 60000, Gamma=0.5,2, h=0,0.05, both guides, float64 and four repeats: W64 baseline only at h=0.05 (reuse the base pilot at h=0), W256/W1024, equilibration4 at W1024 and forward2 at W1024. Every comparison changes one parameter; measurement1/cycles4/branch0.1 are fixed. This representative feasibility subset does not replace the eight-disorder Stage C qualification.

The original 27,328-task tiny-probe queue was paused at 11,267 completed tasks after the requested L10 task `b5758ffa8a5e6ee833cf4dc5` finished. That queue used substantially shorter times than the notebook; its results remain preliminary implementation/precision evidence, not Stage B completion. Completion never changes `ground_state_qualified` or `final_data` to true.

Four-replica outputs retain q, q2, q4, equal-time connected spectra, spin spectra and conventional sublattice spin matrices, with cycle-level samples and ancestry. Energy and growth-energy traces are retained. Derived ratios are formed after disorder averaging under the conventions in the production notebook.

## Recovery

Do not relaunch completed checks, modify frozen source snapshots, or clear failure records without review. The scheduler verifies scientific source hashes and task IDs, skips valid completed outputs and resumes pending checkpoints. To pause a stage, signal only the PID in that stage's `supervisor.pid`; workers checkpoint at their next branch boundary. A waiting follow-up has its own PID and must also be paused when stopping the full sequence. A saved `PAUSE.json` requires review before resumption. The original `pipeline/PAUSE.json` remains as evidence of the deliberate handoff; do not resume the superseded short-probe queue.

The first completion-driven scheduler had a lazy-generator lane-capture bug. It was corrected using eager lane partitioning and duplicate-active-task rejection, verified over the full task list. The paused checkpoint was validated, completed results preserved, and the incident archived under `pipeline/reviewed_failures/scheduler_queue_collision`. A regression test protects lane separation.

For a future approved continuation, preserve the old launch/deadline record, set the next bounded deadline in a new documented operational launch record, then run the corrected scheduler detached with the existing checkpoint and task identities. Do not silently extend the current process window.

## Outstanding scientific gates

Stage B analysis retains every alarm and cycle; uncertainty uses independent populations within equally weighted disorders. Single-disorder escalation SE does not estimate disorder scatter. Stage C costing currently enumerates a provisional 11-configuration linear-work scenario with 30% contingency, not a feasible measured budget. Equal-cost comparisons, cold/warm-cache profiling, event counts and isolated timing components remain open. The frozen runner is not modified while the pilot is active.

The 392 exact references, 392 direct-guide checks, 3,136 precision ensemble runs and 784 finite-forward reference contexts are complete. Of 147 short-setting comparisons, 40 approximate paired-disorder 95% bounds meet the declared tolerances and 107 remain unresolved. These are pointwise approximate bounds; unresolved bounds do not establish a precision bias. Pointwise float32/float64 agreement and short independent ensembles do not certify long-time precision. Further gates include population/time/cadence convergence, alternative starts, ancestry recovery, fourth-moment/connected-ratio error targets, finite-size compatibility and a measured final-campaign budget. Poor-ancestry outputs remain visible and are never discarded to improve agreement.
