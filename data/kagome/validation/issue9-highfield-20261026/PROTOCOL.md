# L6 stronger-field convergence screen

Declared after the low-field Gamma/sigma=0.05 campaign failed to converge. The user proposed increasing Gamma to investigate the paramagnetic regime. Test Gamma/sigma=3 and 5 at sigma=1, retaining L6, periodic boundaries, sample0, h=0, two replicas and the flat guide. These fields are candidate paramagnetic controls; no critical field or phase assignment is assumed for this disordered finite sample.

Use the identical frozen solver from issue9-energy2048-20261026. At each field run eight independent populations at 5,000 and 10,000 walkers through 64 blocks, tau_block=0.2, total imaginary time=12.8. Stronger fields increase the spin-flip rate, so this bounded first screen uses shorter projection than the low-field campaign. Both fields use the same physical projection windows. Retain all transients (n_equilibrate=0) and disable forward cycles. The results are energy diagnostics, not equilibrium production data or overlap estimates.

SeedSequence(20261026).spawn(32) supplies eight disjoint children for each (Gamma, walker count) combination. Compare late windows [32:48] and [48:64], covering time 6.4–9.6 and 9.6–12.8. Also report terminal half-windows for prefixes of 16, 32 and 64 blocks. Use independent population means as uncertainty units and descriptive 95% Student-t intervals (7 degrees of freedom); for the independent walker-count contrast use a Welch interval. The working drift/contrast tolerance is ±0.108 total energy (0.001 sigma per spin), retained from the prior protocol and not a user-specified accuracy requirement. Matching stability does not prove absolute accuracy.

For each Gamma evaluate two normalized product-state references: the all-X state (energy -N*Gamma at h=0), and the saved low-field optimized product state reevaluated at the new Gamma. Their minimum is a valid upper bound E0 <= Evar. The old -143.6366 bound is specific to Gamma=0.05 and is not reused as a stronger-field value. Report the second-order high-field expression -N*Gamma-sum(J^2)/(4*Gamma) for context only; it is not a bound or exact ground-state energy.

Before launch verify source hashes, direct repeatability and the uncoupled J=0 limit on L6, for which E=-N*Gamma exactly and the flat guide is exact. Estimate runtime from a short remote benchmark. Keep at most 16 workers, one BLAS thread each, and retain all solver result fields, settings, source hashes, logs, exit status and plots. No solver dynamics or initialization changes are needed. Keep the instance powered on.

This first stage cannot certify a phase, susceptibility or a production block count. If energy convergence improves, extend projection and check population bias, then validate pure correlations/overlap and forward time. In the Gamma/sigma -> infinity limit q2 -> 1/N and chi_SG -> 1; at finite field interactions give corrections. Do not infer a thermodynamic transition from this one size and disorder sample. Successful stronger-field convergence does not resolve the earlier weak-field failure. Production remains disabled for this exploratory screen.
