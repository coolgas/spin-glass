Disorder-averaged overlap distributions at $h=0.15$¶

Chosen longitudinal field: $h=0.15$, fixed for every exact and Monte Carlo result in this notebook. The transverse field $\Gamma$ takes values 0.60 and 0.65; $h$ is held fixed as $\Gamma$ changes.

Scan update: the figures below preserve the dated $\Gamma=0.60,0.65$ measurements. The requested scan uses $\Gamma=0.55,0.56,\ldots,0.70$ for $L=4$, and $\Gamma=0.55,0.56,\ldots,0.60$ for $L=6$, with $\Delta\Gamma=0.01$ at the same fixed $h=0.15$, to measure how the distribution width changes. Those pending data are not included in these snapshot curves.

The wider search tests a possible shift toward larger $\Gamma$ as $L$ increases at fixed $h$. The original $L=6$ campaign also covers $\Gamma=0.60,0.65,0.70,0.85,1.00$; its low-field fine grid is only a supplement. Higher-field coverage will bracket any candidate glassy regime before refining the relevant interval. The direction of the shift and the existence of glassy order remain to be established from matched disorder averages and connected correlations.

Hamiltonian and two-body disorder. Periodic kagome nearest-neighbor bonds are generated once per disorder sample, with $$H=\sum_{\langle ij\rangle}K_{ij}Z_iZ_j-h\sum_i Z_i-\Gamma\sum_i X_i, \qquad K_{ij}=1+0.5u_{ij},\quad u_{ij}\overset{\mathrm{iid}}\sim U(-1,1).$$ Thus $K_{ij}\sim U(0.5,1.5)$, independently on each undirected nearest-neighbor edge; all bonds are antiferromagnetic and their mean strength sets the energy unit. Frustration comes from kagome geometry. The implementation stores $J_{ij}=-K_{ij}$ in the equivalent convention $-\sum J_{ij}Z_iZ_j$. For reproducibility, NumPy default_rng(SeedSequence([20261027, L, sample_id, 1])) draws one uniform variate per bond in the lattice bond-list order; the final 1 specifies periodic boundaries. These are quenched couplings: the same bonds are held fixed through training, MC and projection, across both guide families, all seeds and every $\Gamma$ for a given $(L,\mathrm{sample\_id})$. $L=2$ uses IDs 50000–50007 and $L=4$ uses 60000–60007. Different sizes have different bond realizations, even if an ID is reused. Couplings are never selected or reweighted by the observed shape of $P(q)$.

Only disorder averages are shown at $\Gamma=0.60,0.65$. The $L=2$ panels overlay exact guide, exact ground-state, and available MC/GFMC curves; $L=4$ uses before projection and after projection columns. Each curve gives equal weight to eight disorders. Capped error bars are $\pm1$ standard error of the disorder mean ($s_J/\sqrt{8}$), pointwise in $q$. They describe finite-ensemble variation and do not bound mixing, finite-population or finite-forward-time errors.

$q=N^{-1}\sum_i s_i t_i$ uses independent physical replicas of the same disorder. $P(q)$ is probability mass per allowed overlap; connecting lines are visual aids. There are two figures: $L=2$ with exact and Monte Carlo comparisons, and $L=4$. All outputs were computed and executed on AutoDL.

def mean_se(values):
    a=np.asarray(values,dtype=float)
    assert len(a)==8
    np.testing.assert_allclose(a.sum(1),1,atol=1e-12)
    return a.mean(0),a.std(0,ddof=1)/np.sqrt(len(a))
def curve(ax,q,values,label,color,fmt='o-',alpha=1):
    if q is None:
        ax.text(.03,.96-.065*len(ax.texts),label+' pending (complete ensemble required)',
                transform=ax.transAxes,va='top',fontsize=7,color=color)
        return
    mean,se=mean_se(values)
    ax.errorbar(q,mean,yerr=se,fmt=fmt,color=color,ms=3,lw=1.15,
                elinewidth=.75,capsize=2,capthick=.75,label=label,alpha=alpha)
def guide_group(rows,L,g,kind):
    group=[r for r in rows if r['task']['L']==L and r['task']['gamma']==g
           and r['task']['kind']==kind and r.get('selected',True)]
    group=sorted(group,key=lambda r:r['task']['sample_id'])
    if allow_pending and len(group)!=8:
        return None,None
    assert len(group)==8 and len({r['task']['sample_id'] for r in group})==8
    return np.array(group[0]['q_grid']),np.array([np.mean([s['mass'] for s in r['starts']],axis=0) for r in group])
def projected_group(L,g,kind):
    group=[r for r in projected if (r['task']['L'],r['task']['gamma'],r['task']['kind'])==(L,g,kind)]
    ids=sorted({r['task']['sample_id'] for r in group})
    if allow_pending and (len(group)!=16 or len(ids)!=8):
        return None,None
    assert len(group)==16 and len(ids)==8
    values=[]
    for sid in ids:
        rs=[r for r in group if r['task']['sample_id']==sid]
        assert {r['task']['repeat'] for r in rs}=={0,1}
        values.append(np.mean([r['mass'] for r in rs],axis=0))
    return np.array(group[0]['q_grid']),np.array(values)

for r in projected:
    p=np.array(r['mass']); q=np.array(r['q_grid'])
    assert np.all(p>=0) and np.isclose(p.sum(),1)
    np.testing.assert_allclose([q@p,q**2@p],[r['q'],r['q2']],atol=1e-12)
rows=[]
for L in [2,4]:
    for g in [.6,.65]:
        for kind in ['jastrow','rbm_2']:
            q,p=projected_group(L,g,kind)
            if q is None:
                continue
            rs=[r for r in projected if (r['task']['L'],r['task']['gamma'],r['task']['kind'])==(L,g,kind)]
            mean=p.mean(0)
            sample_means=p@q
            within_variance=float(np.mean(p@(q*q)-sample_means**2))
            between_variance=float(np.var(sample_means))
            np.testing.assert_allclose(within_variance+between_variance,q**2@mean-(q@mean)**2,atol=1e-12)
            magnetizations=[]
            for r in rs:
                with np.load(folder/r['raw_file']) as data:
                    spin_mean=data['tags'].mean(3)
                    magnetizations.append(float((data['counts']/r['task']['walkers']*spin_mean).sum(2).mean()))
            tv='—'
            if L==2:
                truth=np.mean([r['exact']['pq'] for r in exact if r['gamma']==g and r['sample_id'] in range(50000,50008)],axis=0)
                tv=f'{np.abs(mean-truth).sum()/2:.4f}'
            rows.append([L,g,names[kind],f'{q@mean:.5f}',f'{np.sqrt(q**2@mean-(q@mean)**2):.4f}',
                         f'{within_variance:.5f}',f'{between_variance:.5f}',
                         f'{np.mean(magnetizations):.4f}',f'{mean[q<0].sum():.5f}',
                         tv,f"{sum(r['ancestry_alarm'] for r in rs)}/16"])
